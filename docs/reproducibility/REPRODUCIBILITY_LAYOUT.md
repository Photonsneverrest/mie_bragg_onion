# Reproducible repository layout

```text
mie_bragg_onion/
  src/bragg_onion/                 # versioned library code
  scripts/
    sweeps/                        # production sweep entry points
    analysis/                      # analysis scripts, no embedded raw data
    figures/                       # one script per publication figure
  configs/                         # JSON/YAML parameter grids
  data/
    raw/                           # immutable calculator outputs, not edited
    processed/                     # screened/interpolated plotting copies
    audits/                        # every masked/interpolated point
  outputs/
    figures/main/
    figures/SI/
    tables/
  manuscript/snippets/             # self-contained .tex sections
  env/environment.yml
  CITATION.cff
  README.md
```

## Rules
1. Raw outputs are immutable.
2. Plot cleaning produces a new file and an audit table.
3. Every figure script accepts input/output paths and an optional Matplotlib style.
4. Every production run writes metadata, a task manifest, package versions and Git commit.
5. Published figures are regenerated by a single `make publication` target.
6. Large raw data should be archived on Zenodo; GitHub stores code, configs, lightweight tables and DOI links.
